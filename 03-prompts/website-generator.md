- Editorial display font + clean UI font.

- Soft gradients, glass panels, fine borders and realistic shadows.
- Avoid excessive rounded cards, loud gradients, stock-template layouts and childish effects.

- Add staggered blur/fade-up entrance animations.
- Add hover micro-interactions to CTAs, navigation and key visual elements.

COPY
